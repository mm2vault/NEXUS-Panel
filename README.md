# NEXUS Panel

Modern, responsive oyun sunucusu kontrol paneli arayüzü.

## Özellikler
- Koyu tema, mor neon ve glassmorphism tasarım
- Responsive sidebar ve mobil alt navigasyon
- Sunucu başlatma/durdurma/yeniden başlatma simülasyonu
- RAM, CPU, oyuncu ve uptime göstergeleri
- Canlı demo konsolu ve komut alanı
- Sunucular, dosyalar ve ayarlar ekranları

## Çalıştırma
`index.html` dosyasını tarayıcıda açabilir veya GitHub Pages ile yayınlayabilirsin.

## Önemli
Bu sürüm yalnızca frontend demosudur. Sunucu işlemleri gerçek Minecraft sunucusuna bağlanmaz. Gerçek kullanım için kimlik doğrulamalı bir backend, sunucu yönetim API'si ve güvenli yetkilendirme gerekir.
